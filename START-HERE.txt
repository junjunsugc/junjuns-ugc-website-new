JUNJUNS UGC — ORIGINAL SCRAPBOOK DESIGN + ONLINE CONTENT EDITING

The visual design and existing pages are preserved. This version adds content files
that can be edited through Pages CMS, a GitHub-based visual content editor.

SETUP (one time, no VS Code required):
1. Create a GitHub account and a NEW repository for this portfolio.
2. Upload the CONTENTS of this folder to the repository root, including the hidden
   .pages.yml file (important). GitHub's Add file > Upload files supports folder files;
   for many files, GitHub Desktop is an alternative.
3. In Netlify: Add new project > Import an existing project > GitHub > select repo.
   Netlify reads netlify.toml and runs node build.js on each deploy.
4. Go to https://pagescms.org/ and sign in with GitHub. Authorize the repository.
   Select your repository. You should see Website Settings and Portfolio Projects.
5. Upload a portrait, edit the homepage text, add photos/videos and save/publish.
   Pages CMS commits changes to GitHub; Netlify automatically redeploys.

IMPORTANT:
- This is NOT a live authenticated editor until you connect your own GitHub and Netlify.
- Changes are not immediate: wait for the Netlify deploy to complete.
- Photos/videos must be stored in the repo. GitHub's normal per-file limit is 100 MB;
  large videos should be compressed or hosted externally. Hosting video on GitHub
  can also be inefficient for repository size and bandwidth.
- This setup does not edit page layouts; it edits the homepage introduction,
  portrait, contact email, and portfolio project titles, covers, videos, descriptions.
- If the CMS has trouble uploading MP4s, host videos elsewhere and change the video
  field to a string URL in .pages.yml, or ask for a hosted media-storage integration.
- Verify Pages CMS config compatibility and media upload limits with your account.
- Make sure your website's legal Impressum and privacy policy are complete before launch.
- Do NOT place private tokens/passwords in site files. CMS login is via GitHub.
- Project data is in content/projects/*.json; content/projects.json is automatically
  regenerated by the Netlify build whenever you add or delete projects.
